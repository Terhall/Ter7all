# Ter7all

AI-Powered Smart Tourism Platform that helps travelers plan, explore, book, and manage their entire journey from one place.

---

## Features

- AI Trip Planner
- AI Tour Guide
- AI Chat Assistant
- Authentication & Authorization
- Google OAuth Login
- Email Verification
- Forgot Password & Reset Password
- Tourist Attractions
- Hotels
- Restaurants
- Activities
- Travel Agencies Marketplace
- Tour Packages
- Booking System
- Favorites
- Reviews & Ratings
- Budget Planner
- Interactive Maps
- Transportation
- Weather Forecast
- AI Translator
- Notifications
- Community
- User Dashboard
- Travel Agency Dashboard
- Admin Dashboard
- File Uploads
- Responsive Design
- Dark & Light Mode

## Project Goal

Ter7all aims to provide tourists with a complete travel experience by integrating trip planning, booking, AI assistance, transportation, accommodation, restaurants, travel agencies, and smart recommendations into one intelligent platform.
